2. Time-Boxed Exploratory Testing Sessions

Session 1: Task Creation & Boundary Validation Duration: 30 Mins | Scope: Add Task Module
Charter: Explore task creation workflows across input lengths, special characters, whitespace combinations, duplicate titles, and due dates.
  • Valid tasks with varying priority and categories created smoothly.
  • Empty titles and titles < 3 characters correctly rejected with red error messages.
  • Discovered BUG-001: Whitespace-only string passed HTML validation before being trimmed in JS.
  • Discovered BUG-002: 100-character max limit enforced silently without live counter.
Session 2: CRUD Operations & State Transitions Duration: 30 Mins | Scope: Edit, Toggle, Delete
Charter: Exercise rapid state transitions, item modifications via modal dialog, deletion cascades, and localStorage persistence.
  • Completion toggle reliably strikes through title and updates active/completed metrics.
  • Discovered BUG-003: Task edit modal permitted renaming an existing task to duplicate an active task's title.
  • Discovered BUG-004: Delete action triggers immediately without confirmation dialog.
Session 3: Search, Multi-Filter, and Sorting Combinations Duration: 25 Mins | Scope: Navigation & Data Queries
Charter: Evaluate interaction between real-time search queries, active category filters, and sorting criteria.
  • Real-time search functions correctly on both title and description fields.
  • Filtered lists reflect live additions and completion toggles accurately.
  • Discovered BUG-005: Sorting by due date groups tasks with empty due dates at bottom.
Session 4: Accessibility, Theme & Cross-Environment Consistency Duration: 20 Mins | Scope: Theme, A11y, Visuals
Charter: Review dark/light theme switching, responsive sidebar collapse, keyboard shortcuts, and screen elements.
  • Dark/Light mode switches cleanly and persists across page reloads via localStorage.
  • Discovered BUG-006: Hover-only task action buttons were difficult to access without mouse hover.
  • Discovered BUG-007: Inconsistent OS emoji styling (now addressed with clean vector SVGs).

3. Identified Defect Catalog (Encompassed Bug Reports)

BUG-001 Severity: Minor Status: Resolved
Whitespace-only task titles bypassed initial empty-check
Steps to Reproduce: Enter spaces in task title input and click Add Task. Initially, input with spaces bypassed native empty check before trimming was enforced.
Module: Add Task Taxonomy: Validation Priority: P3 Fix: Enforce title.trim().length >= 3
BUG-002 Severity: Trivial Status: Documented
Missing live character count for 100-character title limit
Steps to Reproduce: Type long text into title. Input stops taking characters at 100 characters without visual countdown indicator.
Module: Form UI Taxonomy: Usability / UI Priority: P4 Recommendation: Add helper text displaying current character count
BUG-003 Severity: Minor Status: Documented
Edit modal allows renaming a task to match an existing active title
Steps to Reproduce: Create Task A and Task B. Open Edit modal for Task B and rename to "Task A". The change is saved without duplicate collision warning.
Module: Task Edit Taxonomy: Validation Priority: P3 Fix: Add duplicate check in edit form submission handler
BUG-004 Severity: Trivial Status: Documented
Immediate deletion without user confirmation dialog
Steps to Reproduce: Click the delete button on any task item. The task is removed immediately from localStorage without a confirmation prompt.
Module: Task Delete Taxonomy: UX / Usability Priority: P4 Recommendation: Add optional undo toast or lightweight confirmation modal
BUG-005 Severity: Minor Status: Resolved
Due date rendering casing mismatch with automated assertion
Steps to Reproduce: Add task with due date. CSS text-transform rendered date in all uppercase ('DEC 31, 2027'), causing case-sensitive string assertion failures.
Module: Task Display / CSS Taxonomy: Visual / Functional Priority: P2 Fix: Applied text-transform: none; to .tag-due
BUG-006 Severity: Minor Status: Resolved
Action buttons hidden until hover prevented easy accessibility
Steps to Reproduce: Navigate task list via keyboard Tab key. Edit and delete buttons remained invisible until mouse hovered over task row.
Module: Accessibility Taxonomy: A11y Priority: P2 Fix: Added :focus-within and ARIA attributes
BUG-007 Severity: Trivial Status: Resolved
Emoji characters rendered inconsistently across platforms and looked AI-generated
Steps to Reproduce: View web app on macOS vs Windows vs Linux. System emojis rendered with varying color schemes, sizes, and aesthetic quality.
Module: Visual / UI Taxonomy: Compatibility / Aesthetics Priority: P4 Fix: Replaced all system emojis with crisp, responsive SVG icons
